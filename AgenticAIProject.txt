1. Executive Summary
This project explores the application of Agentic AI to automate financial and inventory analysis within Enterprise Resource Planning (ERP) systems, specifically Tally Prime. Unlike traditional automation scripts, this system utilizes a Multi-Agent System (MAS) architecture where autonomous AI agents collaborate to perform complex reasoning, tool usage, and natural language reporting. The current prototype focuses on Inventory Optimization, identifying critical stock levels from raw Tally exports and generating executive summaries without human intervention.

2. Core Problem Statement
Small and Medium Enterprises (SMEs) relying on Tally ERP often face:

Data Overload: Tally generates comprehensive data, but extracting actionable insights requires manual Excel manipulation.

Latency: Business owners often wait days for accountants to generate simple status reports.

Static Reporting: Traditional reports (PDFs/Excels) lack context and narrative explanations.

3. Technical Architecture & Implementation
The system implements a decoupled architecture separating the Agentic reasoning engine from the web interface.

3.1 The Agentic Core (CrewAI)

The intelligence layer is built using CrewAI and Google Gemini 2.5 Flash, orchestrated in a sequential process.

Agent 1: Inventory Analyst

Role: Data processing and logic application.

Tool Usage: Custom Python tool (Inventory Analysis Tool) that utilizes pandas to clean Tally exports, parse mixed-type columns (e.g., "500 pcs"), and categorize stock into 'Out of Stock', 'Low Stock', and 'Critical'.

Goal: To mathematically verify inventory status and output structured error/success signals.

Agent 2: Business Reporter

Role: Executive communication.

Context Awareness: Receives the technical output from the Analyst.

Goal: Synthesize the Analyst's findings into a natural language summary suitable for a business owner, removing technical jargon.

3.2 Backend & Data Pipeline (Flask)

API Layer: A Flask REST API exposes endpoints for file uploads and health checks.

File Handling: Implements secure filename handling and dynamic directory management (/data for input, /reports for output).

Data Transformation: The system ingests .xlsx files exported from Tally, performs numeric cleaning (removing units like "kgs", "nos"), and regenerates a multi-sheet Excel report containing isolated critical data points.

3.3 Frontend Interface (React)

User Experience: A modern, responsive UI ("InventoryAIgent") designed to mimic a "Story Board."

Visual Feedback: Users see the "thought process" of the AI, visualizing when the Analyst is "crunching numbers" and when the Reporter is "detecting trends," bridging the gap between black-box AI and user trust.

4. Current Features (Stock Analysis Module)
The current iteration successfully implements:

Automated Ingestion: Parsing raw Tally "Stock Summary" exports.

Categorization Logic:

Out of Stock: Closing Balance == 0.

Low Stock: Closing Balance > 0 AND < 5.

Critical: Negative stock (indicating data entry errors or system flaws).

Multi-Format Output: Delivers both a processed Excel file and a textual summary of the findings.
